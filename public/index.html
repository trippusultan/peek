Cookieless by design

Visitor identity is a daily-rotating hash of IP and user agent, kept entirely server-side. No cookies, no consent banners, no fingerprinting.

identity = hash(ip + ua + salt) / rotates daily

353 B snippet

One line of JavaScript loaded from your own domain. It never touches a third-party server, ever.

one line of JS / gzipped / server-relative

One process

Express, geoip-lite and SQLite in a single Node server. Nothing to orchestrate, no queue, no warehouse.

node server.js / SQLite on disk

Realtime

The live counter and the daily chart update on every request. No batch jobs, no polling, no stale numbers.

1

Add the snippet

Visit your site

Each request is counted as a real visit. No JavaScript is needed on the visitor side.
