Cookieless by design

Visitor identity is a daily-rotating hash of IP and user agent, kept entirely server-side. No cookies, no consent banners, no fingerprinting.

Live in three steps.

1

Add the snippet

Paste one script tag into any page. It beacons back to wherever it was loaded from.

<script defer data-site="your-site-name" src="https://YOUR-RENDER-URL/s.js"></script>
2

Visit your site

Each request is counted as a real visit. No JavaScript is needed on the visitor side.

3

Watch it live

The dashboard updates with current visitors, sources, pages and devices.

Peek makes no external requests and keeps every record in a SQLite file on your own server. There is no account, no cloud, and nothing to sell. The only promise it makes is the one it cannot break.
